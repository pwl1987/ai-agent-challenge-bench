# 执行与评分协议

## 执行

评测器固定挑战版本、基础镜像/运行时、依赖锁和输入种子。先建立隔离工作区，再执行 `runtime.command`；网络默认关闭，允许列表必须在挑战文件中声明。所有 stdout/stderr、退出码、资源计量和测试结果写入结果目录。

## 证据包

证据包至少包含：挑战 JSON、挑战版本、被测提交 SHA、运行时摘要、执行命令、输入种子、公共测试清单、原始结果摘要、资源计量和生成时间。大文件只保存哈希与受控 artifact 引用。

## 复现

评测器在同一版本干净检出上至少重跑一次；随机挑战固定种子，非确定性输出使用性质断言而非逐字比较。两次结果不一致时状态为 `UNSCORED`，并附上差异摘要。

## 抗作弊

公共测试之外保留隐藏测试；测试输入、参考解和评分映射与 Agent 工作区隔离。禁止修改测试、读取隐藏输入、联网调用外部求解器、伪造结果文件或硬编码当前样例。检测到作弊时直接 `FAIL`，不继续计算质量分。

## 评分记录

评分器输出 JSON：`status`、`score`、四个维度分数、独立效率指标、`reasons[]`、证据哈希和评测器版本。评分器遇到缺失字段、版本不匹配、测试未运行或证据不能验证时输出 `UNSCORED`。
