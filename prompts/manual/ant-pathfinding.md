# 人工提示词：蚂蚁群体寻路与避障

你是一个负责交付可运行代码的 AI 编程 Agent。请在当前空项目目录中完成一个可复现的 Python CLI 项目。挑战版本固定为 ant-pathfinding v0.1.0。

## 目标

实现一个蚂蚁群体寻路模拟器。输入是二维网格、障碍物、起点、终点、蚂蚁数量、最大迭代次数和随机种子；输出是机器可读 JSON。模拟器应通过信息素更新或等价的群体搜索过程寻找合法路径，并报告路径长度、迭代次数、种子和运行耗时。

## 必须支持

- 起点和终点都可通行。
- 起点等于终点。
- 无路可达。
- 窄通道、多个分叉和较大网格。
- 相同输入和相同种子重复运行得到相同 JSON 结果。
- 路径不得穿过障碍，也不得跳过网格相邻关系。
- 失败时输出明确的 status 和 reason，不要伪造路径。

## 交付边界

请先检查当前目录，不要假设已经有代码。你可以自行选择标准库或最小依赖，但不得联网下载运行时外的服务，不得读取项目目录以外的秘密文件，不得修改公共测试来制造通过。

建议提供：

- src/main.py
- 一个明确的输入格式说明
- tests/public/test_basic.py
- tests/public/test_edge_cases.py
- requirements 或 pyproject 文件
- README.md
- 运行结果样例

CLI 至少应支持从 JSON 文件或 stdin 读取输入，并把结果写到 stdout。输出对象至少包含 status、path、length、iterations、seed、wall_seconds。

## 实现要求

- 固定随机种子；不要使用当前时间作为算法随机源。
- 对不可达输入返回 status=UNREACHABLE 或等价明确状态。
- 采用确定性的邻居排序，避免同种子下仍因集合遍历顺序产生漂移。
- 对输入尺寸、蚂蚁数量和迭代次数做上限检查，超限时安全失败。
- 关键算法参数写入结果或运行摘要，便于复现。

## 测试要求

至少编写并运行：

1. 一个存在唯一通路的网格。
2. 一个起终点相同的网格。
3. 一个完全不可达的网格。
4. 一个多解网格，验证路径合法而不是硬编码某一条路径。
5. 相同种子运行两次，比较规范化 JSON。
6. 非法输入，验证退出码和错误信息。

测试必须验证结果契约，不得只检查进程退出码。

   - 任何未完成项
