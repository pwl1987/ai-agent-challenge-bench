# S01｜蚂蚁军团智能寻路与动态避障（单文件 HTML 长提示词）

你是一名资深实时图形工程师、群体智能算法工程师和技术美术。请制作一个完整的单文件 HTML，表现可交互的蚂蚁军团在二维/伪 3D 地图中的寻路、觅食、信息素反馈和动态避障过程。最终只交付完整 HTML，不输出解释，不省略代码。

## 一、交付与运行

HTML、CSS、业务 JavaScript 和 shader（如使用）全部内联。唯一允许的外部代码依赖为固定版本 Three.js 或 Canvas 2D 所需的浏览器原生 API；不得使用外部图片、视频、模型、字体、音频或网络 API。通过本地 HTTP 服务打开即可运行；WebGL2 不可用时应降级到 Canvas 或显示可读错误。

初始加载后显示 t=0 的清晰地图、蚂蚁、障碍、巢穴和食物，保持暂停并提供明显播放按钮。依赖或渲染初始化失败时不能无限等待。

## 二、场景与时间

地图使用统一坐标和明确网格尺寸。包含巢穴、食物源、墙体/障碍、可移动障碍和至少两条可选路径。固定 seed=19450806 生成布局，重播不重抽。

提供 0–60 秒时间轴：

0–5 秒展示巢穴、食物和蚂蚁；
5–20 秒蚂蚁探索并留下信息素；
20–40 秒群体逐渐强化较优路径；
40–55 秒加入动态障碍并观察重规划；
55–60 秒镜头拉远展示最终路径、剩余食物和统计。

阶段可重叠，不能用预先录制的路径替代真实搜索。

## 三、真实算法状态

每只蚂蚁必须有位置、速度/步进状态、当前路径、已访问节点、是否携带食物和是否回巢状态。地图必须维护障碍、信息素、食物量和巢穴状态。

每个固定仿真步至少执行：邻居选择、边界和障碍检查、启发式项、探索/利用决策、到达判断、信息素沉积、信息素蒸发、动态障碍更新和统计记录。邻居顺序必须固定，随机数来自 seed，不能随帧率重抽。

路径不能穿过障碍或跳过网格相邻关系。动态障碍出现后必须重新验证路径并触发重规划。

## 四、渲染与交互

提供播放/暂停、重播、单步、时间轴、0.5×/1×/2×、自由观察、显示/隐藏信息素、障碍编辑、低/高画质和可折叠诊断面板。

暂停必须冻结蚂蚁、信息素、粒子、shader 时间和电影镜头；自由相机仍可移动。用户拖动时间轴时暂停，seek 完成后恢复拖动前的播放意图。

用颜色或密度显示信息素强弱，但不得只显示一条预画路径。地图、蚂蚁、障碍和食物必须有空间关系和可读遮挡。

## 五、评测接口

通过 window.demo 暴露 ready、pause()、play()、reset()、step(count)、seek(seconds)、setQuality("low"|"high") 和 getState()。

getState 至少返回 seed、time、playing、seeking、playbackRate、cameraMode、antCount、reachedFoodCount、returnedNestCount、bestPathLength、iteration、gridResolution、fixedDt、pheromoneMin、pheromoneMax、dynamicObstacleCount、nonFiniteCount 和 determinismHash。

所有字段必须来自真实运行状态。非法 seek、NaN、Infinity 和超出范围参数必须安全拒绝。连续 seek 以最新目标为准，旧请求不得覆盖新状态。

## 六、测试矩阵与证据

至少测试：起点等于终点、唯一通路、多分叉、完全不可达、动态障碍、100/1000/5000 只蚂蚁、暂停/单步/重置、固定 seed 两次运行和不同 seed。

提交 README、运行命令、测试命令、截图/录屏、性能表和 evidence/summary.json。summary 至少包含 seed、固定步长、网格、蚂蚁数、运行时版本、平均帧时间、渲染质量、确定性摘要和未评测项。

## 七、抗作弊与最终边界

不得用视频、整幅图片、纯 DOM 动画、写死路径、假统计或只播放预设动画冒充算法。可以提供 BFS/A* 对照，但必须标明 baseline。

无法真实运行、证据不足或浏览器能力不满足时必须标记 UNSCORED。不要宣称官方分数。
