# C03｜三维水流、瀑布与池面汇聚（人工复制版，长提示词）

你是一名资深实时图形工程师、技术美术和数值模拟工程师。请制作一个完整、可运行、可交互的 3D 水流/瀑布演示。挑战版本固定为 3d-fluid-waterfall v0.2.0。

## 一、交付与运行

优先制作单文件 HTML；HTML、CSS、业务 JavaScript 和 shader 全部内联。只允许使用明确锁定版本的 Three.js 及其官方 addons，或在 README 中说明等价技术栈。不得使用外部图片、视频、模型、字体、音频或网络 API；纹理、几何和辅助数据必须程序化生成。

在现代桌面 Chromium 通过本地 HTTP 服务打开即可运行。使用 WebGL2；依赖或渲染初始化失败时显示可读错误，不得无限等待。初始加载完成后显示暂停的清晰 3D 场景，而不是黑屏或只有 HUD。

## 二、场景目标

场景至少包含水源、落差、瀑布、池体、河道/边界、可移动障碍物、地面材质、相机和光源。用户能够观察水流从水源连续下落、与障碍物碰撞、产生溅射并在池面汇聚。

提供暂停、播放、单步、重置、时间轴、自由相机、固定 seed、流量、重力、阻尼和质量档位。暂停必须冻结模拟、粒子和 shader 时间，但自由相机仍可操作。

## 三、统一坐标与固定时间

明确竖直轴和世界单位。使用固定仿真步长，渲染频率与模拟频率分离。相同 seed、相同输入序列和相同目标时间应得到一致的主要状态。

水滴/粒子不能在爆发或重置时凭空重复累积。对象应有回收或休眠条件，越界粒子应进入可解释的边界处理。

## 四、真实模拟要求

必须实现真实的水流状态，而不是只播放下落贴图。至少维护粒子或网格中的位置、速度、寿命/质量和边界状态，并实现：

- 重力；
- 水源注入；
- 与地面、池壁和障碍物的碰撞；
- 碰撞后的速度衰减或反射；
- 溅射/分裂的有界规则；
- 池面汇聚或回收；
- 流量、重力和阻尼参数的实际影响。

可以使用粒子、SPH/PBF、网格或混合近似，但必须明确近似边界，不得宣称工程级流体精度。视觉噪声不能替代运动、碰撞和边界状态。

## 五、渲染与交互

水体应具有可辨识的透明/半透明、反射或折射近似，瀑布和池面必须具有不同空间厚度与亮度。不得用单张图片、视频、全屏遮罩或永远朝向相机的平面冒充主体流体。

设置合理的透明度合成和深度处理：水流不能无条件盖住前方障碍物，后方几何不能穿透不透明池壁。高低画质只改变像素比、采样数和装饰细节，不改变基础模拟状态。

视口需要兼顾 1920×1080 和 390×844；窄屏控件可操作，不要求相同构图。提供可折叠诊断面板，显示粒子数、仿真步、固定步长、平均帧时间、回收数和非有限数计数。

## 六、评测接口

通过 window.demo 暴露：

ready：初始化完成且 t=0 可渲染后为 true；
pause()、play()、reset()；
step(count)：推进有限个固定步；
setQuality(low/high)；
setSeed(number)；
getState()：返回可 JSON 序列化对象。

getState 至少包含 seed、time、playing、particleCount、activeParticleCount、simulationStep、fixedDt、sourceRate、gravity、damping、collisionCount、recycledCount、nonFiniteCount、quality、cameraMode 和 determinismHash。

所有数据必须来自真实运行状态，不得写死为通过验收的统计。非有限值出现时应停止相关更新并显示可读错误。

## 七、测试矩阵

至少覆盖：

1. 初始化后 t=0 可渲染；
2. 暂停时粒子和 shader 时间不推进；
3. 单步只推进规定固定步数；
4. 重置恢复 seed、粒子和时间；
5. 相同 seed 与输入序列产生一致摘要；
6. 水源、障碍物、池壁和重力真实影响状态；
7. 粒子碰撞后不持续穿透；
8. 越界粒子被回收；
9. 高粒子数压力场景；
10. 依赖失败、WebGL2 不可用和非法参数的错误提示。

## 八、性能与证据

至少报告低/高质量、默认粒子数、压力粒子数、平均帧时间、仿真步耗时、峰值内存（若能测量）和非有限值计数。重置、切换质量和重复播放不得泄漏 renderer、纹理、动画循环或事件监听器。

提交 README、运行命令、测试命令、截图或录屏证据、性能摘要和已知限制。无法实际运行的部分必须写未评测或 UNSCORED。

## 九、抗作弊边界

以下不计为通过：预录视频、单张图片、纯 DOM 动画、只改变粒子颜色不改变物理状态、写死粒子统计、没有碰撞或回收、用噪声替代水流、把文字说明当作运行证据。

最终交付优先保证真实可运行、状态一致和可复现，再增加材质细节。不要宣称真实水工或工程级流体预测。
