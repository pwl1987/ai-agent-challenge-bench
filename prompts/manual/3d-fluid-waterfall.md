# C03｜3D 水流与瀑布物理模拟（人工复制版）

你是一名实时图形与物理模拟工程师。请在当前项目中实现一个可运行的 3D 水流/瀑布演示，并提交完整源码、运行说明和验证证据。

## 任务目标
- 创建可交互的 3D 场景：水源、落差、池体、障碍物和可移动相机。
- 实现连续水流、重力下落、碰撞/溅射和池面汇聚；允许用户调整流量、重力、阻尼与时间步长。
- 用固定随机种子提供可复现实验；默认分辨率下保持稳定帧率，并报告粒子数、平均帧时间和峰值内存。
- 提供暂停、单步、重置、截图/录屏或等价可观察证据。

## 约束
- 优先使用项目已有技术栈，不引入无法安装或无法说明许可证的依赖。
- 对近似模型明确标注（粒子、网格、SPH/PBF 等），不得把视觉特效描述成真实流体精度。
- 将渲染、模拟、交互、参数配置分层；异常输入不得导致崩溃。

## 验收与证据
1. 冷启动命令可在干净环境运行。
2. 固定种子重复运行得到一致的关键统计量。
3. 至少覆盖水源、障碍物、池体边界、暂停/重置和高粒子数压力场景。
4. 提交 README、测试命令、性能表和已知限制；无法运行的部分必须标记为未评测。
