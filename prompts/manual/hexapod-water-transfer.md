# 人工提示词：六足机器人倒水

你是一个负责交付可批处理、可复现模拟项目的 AI 编程 Agent。请在当前空项目目录中完成挑战 hexapod-water-transfer v0.1.0。第一阶段允许使用无头简化物理模型；不要为了展示效果牺牲可重复性。

## 目标

模拟六足机器人从起点行走到容器前，保持稳定姿态，将目标水量的至少 80% 倒入目标容器。输入包括地形、机器人初始姿态、步态参数、起点、容器位置、初始水量和随机种子。输出机器可读 JSON，描述步态、碰撞、稳定性、倾倒量、最终姿态和耗时。

## 运行模式

必须提供无头命令，不能依赖窗口或人工鼠标操作。若实现 3D 视图，视图只是可选展示层；评测以无头结果和公共断言为准。

## 必须支持

- 成功任务：可达目标、容器有水、最终姿态稳定、倒水量达到 80%。
- 不可达目标：明确失败原因，不宣称成功。
- 空容器：明确报告 delivered=0 或等价结果。
- 碰撞或倾覆：任务失败并记录事件。
- 固定种子重复运行结果一致。
- 输入参数、物理参数和仿真步长写入结果。

## 安全和工程限制

- 默认断网，不调用外部服务或在线模型。
- 只写入项目目录下的结果目录。
- 不能读取工作区外的凭据、SSH 配置或用户文件。
- 记录依赖、运行时版本和入口命令。
- 任何无法实际模拟的部分必须标注为简化模型，不得把动画截图当作物理证据。

## 推荐交付物

- src/main.py 或等价入口。
- 无头运行命令和输入 JSON 示例。
- tests/public/test_success.py。
- tests/public/test_failure_modes.py。
- tests/public/test_reproducibility.py。
- README.md。
- evidence/summary.json、stdout.json、resource-metrics.json。

## 公共测试至少断言

1. 正常地形上机器人到达容器。
2. delivered_volume / requested_volume >= 0.8。
3. 最终姿态在声明的稳定阈值内。
4. 不可达和空容器返回明确失败状态。
5. 固定种子两次运行的关键字段一致。
6. 碰撞次数、步数、耗时字段存在且类型正确。

## 交付前自检

完成后回报：

- 入口和无头命令。
- 物理模型假设及其限制。
- 测试命令和实际结果。
- 固定种子复跑结果。
- 当前提交 SHA；如果不是 Git 仓库则写 null。
- evidence 文件清单和哈希。
- 未实现的真实物理能力。

不要给官方总分。只交付可验证事实；证据不足时输出 UNSCORED。
