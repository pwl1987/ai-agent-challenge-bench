# 人工提示词：3D 场景与性能测试

你是一个负责交付可运行 3D 技术验证项目的 AI 编程 Agent。请在当前空项目目录中完成 challenge 3d-performance v0.1.0。目标是测量和解释性能，不是只生成一个好看的截图。

## 目标

创建一个可批处理运行的 3D 场景，包含可参数化的几何体、灯光、材质、相机和动画负载。提供无头模式和可选窗口模式，输出帧率、帧时间分位数、CPU、内存、GPU 或渲染后端信息、场景规模和运行时版本。

## 场景档位

至少实现 small、medium、large 三档。每档固定对象数量、三角形数量、光源数量、纹理大小和动画更新规则。档位配置必须写入结果，不能只写“高负载”。

## 必须支持

- 无头模式在没有显示器时运行。
- 固定种子生成同一场景。
- 预热阶段与正式测量阶段分开。
- 报告平均帧率、p50、p95、p99 帧时间。
- 记录丢帧或超时数量。
- 场景无法启动时明确返回 UNSCORED 或 FAIL 原因。
- 相同机器和相同配置重复运行，结果允许有测量噪声但必须记录环境。

## 不得做的事

- 不得把单张截图当作性能数据。
- 不得只报告平均 FPS 而隐藏长尾。
- 不得跨硬件直接比较数值。
- 不得联网下载资源后再把下载时间排除而不记录。
- 不得把人工主观“流畅”写成分数。

## 推荐交付物

- 可运行入口和无头命令。
- scene 配置文件。
- tests/public/test_config.py。
- tests/public/test_output_contract.py。
- benchmark/measure.py 或等价脚本。
- README.md。
- evidence/performance.json、environment.json、command.txt。

## 公共测试至少断言

1. 三个场景档位都有明确配置。
2. 无头命令能启动并返回结构化 JSON。
3. 输出包含 p50、p95、p99、平均帧时间和场景规模。
4. 预热帧不计入正式统计。
5. 固定种子生成的对象摘要一致。
6. 缺失后端或无法测量时输出明确状态，而不是伪造零耗时。

## 交付前自检

请报告：

- 渲染后端、版本、分辨率和是否无头。
- 三个档位的配置摘要。
- 预热帧数、正式帧数和测量窗口。
- 原始指标文件及其哈希。
- 测试命令和实际结果。
- 当前提交 SHA；如果不是 Git 仓库则写 null。
- 测量限制和未覆盖的平台。

不要给官方总分。效率指标独立记录，质量分由评测器在证据完整后计算。
