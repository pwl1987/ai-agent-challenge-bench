# Agent 提示词库

本目录先提供人工复制模式。使用者把一个完整提示词复制到目标 Agent，会话开始前只需要准备一个空项目目录和该挑战的固定版本。

## 使用方式

1. 选择一个 manual 提示词。
2. 将整段内容一次性复制给 Agent。
3. Agent 先回报理解、计划和预计产物，再开始写代码。
4. 人工确认 Agent 已在独立目录工作后，让它执行公共测试。
5. 收集 Agent 输出的提交 SHA、命令、测试摘要和资源信息，交给仓库评分器。

提示词要求 Agent 自己完成实现、测试和证据整理，但不能自行宣称官方分数。评分由独立评测过程完成。

## 模式边界

- manual：当前版本，适合人工复制和单次运行。
- automated：预留给后续调度器、沙箱和结果归档；当前不要求使用。

## 公共约束

每个挑战都要求固定输入、可重放、无网络、机器可读输出，并在无法运行或证据不足时明确报告 UNSCORED。
