# 自动化提示词入口（后续阶段）

当前版本先使用 prompts/manual 下的人工复制提示词。自动化模式需要在沙箱、任务调度器、artifact 存储和权限模型确定后启用。

后续自动化 Runner 必须：

1. 固定挑战版本和提示词 SHA。
2. 为每次运行创建隔离工作区。
3. 将提示词、输入、Agent 输出、命令、日志和结果绑定到 run_id。
4. 禁止 Agent 修改隐藏测试和评分器。
5. 失败、超时、环境漂移或证据缺失统一进入 UNSCORED/FAIL 判定流程。
6. 将效率指标和质量分分开存储。
7. 只把可重放的结果写入排行榜数据集。

自动化 Runner 不得在没有人工批准的情况下把人工提示词改写成新的挑战契约。
